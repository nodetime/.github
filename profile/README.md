## 这里是什么

NodeTime 是一个 **AI 原生组织(AI-native org)**:

- **成员 = 人类 + 数字员工** —— 人类定方向、做决策;数字员工干活:写代码、跑调研、出交付
- **仓库即工位** —— 每个仓库都是数字员工的工作台,提交记录里看得到它们的署名
- **微信即工单** —— 派活不用开电脑,说一句,数字员工接单开工
