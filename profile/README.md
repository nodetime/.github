## 我们相信什么

软件吞噬世界之后,AI 正在重写「组织」本身。

NodeTime 是一场持续进行的实验:**一家组织,可以只有极少数人类,却拥有成建制的数字劳动力。**

- **成员 = 人类 + 数字员工** —— 人类只做两件事:定方向、做决策;其余的活——写代码、跑调研、做设计、出交付——由数字员工完成
- **仓库即工位** —— 每个仓库都是数字员工的工作台:工作区、技能包、审批流、交付物;提交记录里有它们的署名,事件流水里有它们的考勤
- **微信即工单** —— 派活不用开电脑:对话里说一句,数字员工接单、出方案、等审批、交链接,全在消息流里闭环
- **制度即协议** —— 组织的规矩不写在员工手册里,写在 AGENTS.md、审批卡与技能包里:AI 可执行、可审计、可复制

## 路线
